# 🎰 Casino Game

**Casino Game** is an interactive 3D game developed as the **Final
Project for the Interactive Graphics course at Sapienza University of
Rome**.

The project was created to apply the concepts studied during the course
in the development of a complete interactive experience using **WebGL
and Three.js**.

## 🎮 Play the Game

### 👉 [PLAY CASINO GAME](https://sapienzainteractivegraphicscourse.github.io/final-project-cozygraphics/)

No installation is required. The game runs directly in the browser.

------------------------------------------------------------------------

## 🎯 Game Objective

The objective of the game is to **enter the casino and collect as much
money as possible before the time runs out**.

The player starts outside the casino and must find a way to enter it.

Once inside, different casino activities can be used to try to increase
the player's money.

The goal is simple:

> **Enter the casino, play, and finish the game with as much money as
> possible.**

------------------------------------------------------------------------

## 🕹️ How to Play

### Movement

-   **W** --- Move forward
-   **A** --- Move left
-   **S** --- Move backward
-   **D** --- Move right
-   **Mouse** --- Look around

### Interaction

Move close to interactive objects and follow the instructions displayed
on screen.

Some objects and activities inside the game can be activated only when
the player is close enough to interact with them.

------------------------------------------------------------------------

## 🏆 Goal

Explore the game, enter the casino and use the available activities to
increase your money.

Try to obtain the **highest amount of money possible before the game
ends**.
